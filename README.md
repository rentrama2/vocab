# 🌟 KidsVocab Studio 🎈
> **ระบบสร้างและเล่นแบบฝึกหัดคำศัพท์ภาษาอังกฤษภาพการ์ตูนน่ารักสำหรับเด็ก (English Vocabulary Exercise & Worksheet Generator for Kids)**

KidsVocab Studio เป็นเว็บแอปพลิเคชันที่ออกแบบมาเพื่อให้คุณครูและผู้ปกครองสามารถสร้างแบบฝึกหัดคำศัพท์ภาษาอังกฤษที่น่าสนใจ ดึงดูดความสนใจของเด็กชั้นประถมศึกษา (ป.1 - ป.3) ด้วยภาพการ์ตูนสีสันสดใส เสียงอ่านออกเสียงมาตรฐาน และเกมอินเทอร์แอคทีฟ

---

## ✨ ฟีเจอร์หลัก (Key Features)

### 1. ✏️ ระบบใส่คำศัพท์ & Gen อัตโนมัติ (Custom Vocab & Generator)
- **เพิ่มคำศัพท์ตามต้องการ:** ใส่คำศัพท์ภาษาอังกฤษ + คำแปลภาษาไทย + เลือกลายการ์ตูนน่ารัก
- 🖼️ **ระบบค้นหาภาพการ์ตูนให้อัตโนมัติ (Smart Auto-Image Finder):**
  - **Live Auto-Search:** เมื่อพิมพ์คำศัพท์ภาษาอังกฤษ ระบบจะค้นหาภาพการ์ตูนเวกเตอร์สีสันสดใสให้ทันทีโดยอัตโนมัติ
  - **แกลเลอรีตัวเลือกภาพ:** แสดงภาพการ์ตูนที่เกี่ยวข้องให้คลิกเลือกเปลี่ยนได้ทันที 1 คลิก
  - **Bulk Import พร้อมหาภาพ:** นำเข้าคำศัพท์หลายๆ คำพร้อมกัน ระบบจะไล่ค้นหาภาพให้ครบทุกคำโดยอัตโนมัติ
  - **คลังภาพเวกเตอร์คมชัดสูง (SVG):** ภาพไม่แตก คมชัดระดับ 300dpi แม้พิมพ์บนกระดาษ A4
- **หมวดหมู่คำศัพท์สำเร็จรูป ป.1:**
  - 👃 **My Body (ร่างกายของฉัน):** orange, nose, mouth, eyes, ear, hand
  - 🐶 **Cute Animals (สัตว์โลกน่ารัก):** cat, dog, rabbit, elephant, lion, bird
  - 🍎 **Yummy Fruits (ผลไม้แสนอร่อย):** apple, banana, watermelon, strawberry, mango, grape
  - 🎨 **Colors (สีสันสดใส):** red, blue, yellow, green, pink, purple
  - 🎒 **School Things (สิ่งของในโรงเรียน):** book, pencil, bag, ruler, chair, table
- **Bulk Import:** วางคำศัพท์ทีละหลายคำได้ เช่น `cat, แมว`

### 2. 🎮 โหมดเกมแบบฝึกหัด 4 รูปแบบ (Interactive Game)
- 🎨 **Picture Match:** ดูภาพการ์ตูนแล้วเลือกคำศัพท์ภาษาอังกฤษที่ถูกต้อง
- 🔊 **Listening Challenge:** ฟังเสียงอ่านภาษาอังกฤษ แล้วเลือกภาพการ์ตูนให้ตรงกัน
- 🧩 **Spelling Scramble:** เกมคลิกเรียงตัวอักษรเพื่อสะกดคำศัพท์ (สนุกเหมือนเล่นตัวต่อ)
- 🇹🇭 **Meaning Match:** ทดสอบความจำความหมายภาษาไทย

### 3. 🎈 มัลติมีเดียเสริมการเรียนรู้
- 🔊 **Text-to-Speech:** เสียงอ่านออกเสียงสำเนียงภาษาอังกฤษมาตรฐาน ชัดเจนสำหรับเด็ก
- 🎵 **Sound Effects:** เสียงประกอบดนตรีสดใส มีเสียงติ๊งเมื่อตอบถูก และเสียงให้กำลังใจ
- ⭐ **ระบบคะแนน & ดาวสะสม:** เสริมแรงเชิงบวกให้เด็กๆ อยากเรียนรู้
- 🎊 **Confetti Celebration:** พลุกระดาษสายรุ้งฉลองชัยชนะเมื่อทำครบทุกข้อ

### 4. 🖨️ โหมดพิมพ์ใบงาน A4 (Printable Worksheets)
- สามารถแปลงชุดคำศัพท์เป็นใบงาน A4 สำหรับพิมพ์ออกมาทำบนกระดาษได้ทันที
- ประกอบด้วย **ตอนที่ 1: โยงเส้นจับคู่** และ **ตอนที่ 2: เติมตัวอักษรที่หายไป**
- มีช่องสำหรับเขียนชื่อ ชั้น เลขที่ และกรอกคะแนน

## 🚀 วิธีเปิดใช้งาน (Getting Started)

1. ดาวน์โหลดหรือ Clone โครงการนี้:
   ```bash
   git clone https://github.com/rentrama2/vocab.git
   ```
2. ดับเบิลคลิกเปิดไฟล์ `index.html` บนเว็บเบราว์เซอร์ใดก็ได้ (Google Chrome, Microsoft Edge, Safari ฯลฯ)
3. ใช้งานได้ทันที ไม่จำเป็นต้องติดตั้งโปรแกรมหรือเซิร์ฟเวอร์เพิ่มเติม

---

## 🛠️ เทคโนโลยีที่ใช้ (Tech Stack)
- **HTML5 & Vanilla JavaScript**
- **Tailwind CSS** (CDN)
- **Web Speech API** (SpeechSynthesis) สำหรับเสียงอ่านคำศัพท์
- **Web Audio API** สำหรับเสียงเอฟเฟกต์ (ไม่ต้องโหลดไฟล์เสียงภายนอก)
- **HTML5 Canvas** สำหรับระบบ Confetti แอนิเมชัน
